# better-zslf

**掌上莲峰**（电子科技大学中山学院，`com.zx.slm`）的第三方开源客户端。

> 🚧 开发中 —— 本仓库当前用作 **issue 跟踪**。客户端源码将随开发进度陆续提交。

## 提交反馈

发现 Bug 或有功能建议？**[→ 新建 Issue](https://github.com/better-zslf/better-zslf/issues/new/choose)**

| 类型 | 适用场景 |
|---|---|
| **功能异常** | 客户端崩溃、功能不正常、数据与官方 App 不符 |
| **新功能建议** | 希望增加或改进某个功能 |
| **其它问题** | 不属于以上两类 |

提交前请注意：

- **请勿在 issue 中填写学号、密码、token 等敏感信息**
- 描述问题时请附上 App 版本与系统版本（表单里有）
- 截图直接拖拽到 issue 编辑框即可上传
