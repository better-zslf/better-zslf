# 开发状态

当前基础应用已可运行，核心逻辑与首批页面已接入；完整业务闭环仍在开发，尚未发布稳定版本。

## 平台与结构

- Kotlin 2.4.21、Compose Multiplatform 1.12.2、Miuix 0.9.4。
- Android 13+；共享 UI 与业务逻辑位于 [shared](<../shared/build.gradle.kts>)。
- iOS 入口使用 SwiftUI 与静态 Shared.framework，详见 [iOS 构建说明](<../iosApp/README.md>)。
- JVM 仅用于宿主机测试，不作为桌面产品发布。

## 已完成的独立检查

最新本机集成报告为 605 个 JUnit 方法、零失败：604 项离线用例与 1 个默认关闭的 Live 门控方法。新增的 6 个文案测试方法含独立字面量、边界及纯 fake 回调顺序验证。另有 55 项诊断脚本及 123 项 scripts 宿主回归通过；宿主脚本与 Native 验收分开计数。Android Debug 构建及 lint 已通过。热水器协议另有 220702 条与原始 WAT/TS 的逐字节差分记录；这些结果不代表实体水控器兼容性。模拟器与账号测试详见[验证记录](<testing.md>)。

[iOS 脚本说明](<../iosApp/README.md#验证状态>)介绍其覆盖范围；当前实际执行状态以[最新验证记录](<testing.md#2026-10-25测试分支集成>)为准。

## 验证原则

- 默认测试不访问学校服务；真实接口测试必须显式开启环境开关与临时环境凭据。
- 账号实测仅覆盖登录及查询，不以空参试探改密、报名、预约或运动写接口。
- 真实接口测试不输出身份字段、请求参数、token 或响应正文。
- 模拟器验证与真机 GPS/BLE 验收分开记录，不以一项替代另一项。
- 分析输入、原始抓包、账号记录与本机工具链不纳入源码仓库。
